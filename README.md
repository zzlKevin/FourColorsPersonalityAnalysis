# 色彩性格测试 · 本地密钥版（Base64 分支）

简体中文 | [English](README.en.md)

一个开箱即用的性格色彩测评小工具：30 道情境题，约 3–5 分钟，从「红 / 黄 / 蓝 / 绿」四个维度给出主导性格、四维得分与详细解读（性格解读、优势、待改进、相处与职场建议）。

**整个工具就是一个 HTML 文件**：用浏览器打开即可测试，无需安装、无需服务器、无需联网。

> 本分支为 **HashCode 分支**，与主分支的「局域网团队版」定位不同：这是一个完全本地运行的测评工具。测试者完成后，结果被编码进一串**报告密钥**——不需要存储任何结果数据，只保留密钥，即可在任意客户端粘贴解析、还原同一份报告。

---

## 本分支与主分支的区别

| | 主分支（局域网团队版） | 本分支（本地密钥版） |
|---|---|---|
| 运行形态 | Go 服务端程序 + 内嵌网页 | 单个 HTML 文件，浏览器打开即用 |
| 结果存储 | 测试记录集中保存在主机 `records.json` | **结果编码进报告密钥，不存储结果数据** |
| 结果调取 | 6 位报告密码 / 管理后台 | 任意设备粘贴 `CSX1-` 密钥即可还原报告 |
| 联网需求 | 需局域网或公网访问 | 核心功能完全离线（仅可选的界面翻译需联网） |
| 管理后台 | 有 | 无（发起人密钥可打开本机记录中心） |

## 核心机制：报告密钥

本分支采用「**密钥即数据**」的设计：

```text
答题完成 ──► 结果打包编码为报告密钥（CSX1-…）──► 只保留密钥，不留存结果数据
                                                        │
任意客户端打开本工具 ◄── 首页粘贴密钥 ◄───────────────────┘
        即可完整还原：姓名、测试时间、30 题作答、四维得分与全部报告内容
```

- 测试提交后，结果页自动生成一串 `CSX1-` 开头的**报告密钥**，其中编码了：姓名、测试时间、30 题作答、四维得分；
- **服务器与本机都不需要保存结果**——密钥本身就是这份报告的完整载体；
- 任何人拿到密钥，在首页「通过密钥查看报告」粘贴，即可在**任意客户端**（手机 / 电脑 / 任何现代浏览器）离线还原同一份报告，无需联网、无需账号；
- 密钥的生成与解析全部在浏览器本地完成（URL-Safe Base64），全程零网络请求。

> **隐私提示**：密钥等同于报告本身（Base64 是编码而非高强度加密）。请只把密钥发给你允许查看结果的人——密钥泄露即结果泄露。

### 两种密钥

| 密钥 | 形态 | 作用 |
|---|---|---|
| **报告密钥** | `CSX1-` 开头，测完自动生成 | 单份报告的载体：分享给他人查看，或自己留档，随时粘贴还原 |
| **发起人密钥** | 8 位数字（默认 `12345678`） | 在首页输入可打开**本机记录中心**，集中查看本机保存的全部记录 |

发起人密钥只是本机记录中心的入口，写在源码 `MASTER_KEY` 常量中，可自行修改。

## 功能特性

- **30 题快速测评**（约 3–5 分钟）：四维得分与主导性格判定，同分并列（两色主导 / 三色并列 / 四色均衡）有明确提示
- **详细报告**：主导性格卡、四维得分图（含「显著主导 / 明显倾向」等分级）、性格解读、优势与待改进、相处与职场建议、辅助色彩
- **报告密钥**：一键复制，发给对方即可查看；对方解析出的报告还可一键「保存到本机」
- **本机记录中心**（凭发起人密钥进入）：查看、删除单条、清空全部，自动保留最近 300 条
- **多种导出**：报告 PNG 长图、TXT 文本存档；记录中心支持导出全部记录 TXT、`.json` 备份导出 / 导入合并（可跨设备迁移，按记录编号去重）
- **零依赖离线运行**：单文件、免构建、免安装；修改 HTML 即生效，无需编译
- **桌面快捷键**：`←` / `→` 翻题，`1–4` 或 `A–D` 快速作答
- **微信适配**：检测微信内置浏览器并提示「在浏览器打开」以完成下载
- **界面多语言（可选）**：页面末尾接入 translate.js 在线翻译，可切换界面语言；如需完全离线，删除文件末尾对应的两段 `<script>` 即可

## 快速开始

1. 下载（或克隆）本分支的 `色彩性格测试.html`；
2. 用任意现代浏览器打开——电脑上双击即可，手机可把文件传到本机后用浏览器打开；
3. 输入名字（可选）→ 开始测试 → 提交后**立即复制报告密钥**保存。

也可以把它放到任意静态托管（GitHub Pages、Nginx、对象存储静态网站等），把链接分享给测试者，访问即测。

> 提示：首页「复制密钥」依赖剪贴板能力，在 HTTPS 或 localhost 环境下体验最佳（其他环境会自动退回兼容方案）。

## 使用流程

**测试者**

1. 打开页面 → 填写名字 → 答完 30 题；
2. 在结果页点击「复制报告密钥」，把密钥发给自己或组织者，也可导出 PNG / TXT 存档。

**报告查看者 / 组织者**

1. 在任何设备上打开同一份 HTML；
2. 首页「通过密钥查看报告」粘贴密钥 → 立即看到完整报告；
3. 需要集中留档时，可点「保存到本机」，之后凭发起人密钥进入记录中心统一查看、导出。

## 计分规则

每题四个选项对应四色，前后 15 题的映射方向相反：

| 色彩 | 第 1–15 题 | 第 16–30 题 |
|---|---|---|
| 红（热情表达型） | A | D |
| 黄（目标主导型） | C | B |
| 蓝（严谨完美型） | B | C |
| 绿（温和稳定型） | D | A |

每个维度满分 30 分：≥12 显著主导，≥9 明显倾向，≥5 中等水平，≥1 相对较弱。

## 数据与隐私

- **零上传**：除可选的界面翻译服务外，工具不发起任何网络请求，测试数据不出设备；
- **本机记录**：仅保存在当前浏览器的 `localStorage`（键名 `csx_records_v1`，上限 300 条）；浏览器禁用本地存储（如隐私模式）时自动退回内存存储，本次会话仍可正常使用；
- **想不留痕**：测完只保留密钥，再到记录中心删除本机记录——结果就只存在于你手里的那串密钥中；
- **换设备**：粘贴密钥即可还原单份报告；或用 `.json` 备份文件迁移全部记录；
- **清除浏览器数据会导致本机记录丢失**，但已保存的密钥 / PNG / TXT / JSON 不受影响，凭密钥随时可还原。

## 自定义

打开 `色彩性格测试.html`，按需修改：

| 想改什么 | 位置 |
|---|---|
| 题目与选项 | `QUESTIONS` 数组（每题 4 个选项） |
| 四色名称 / 主题色 | `DIMS` 对象 |
| 解读 / 优势 / 待改进 / 建议文案 | `PROFILE` 对象 |
| 发起人密钥 | `MASTER_KEY` 常量 |
| 密钥前缀 | `KEY_PREFIX` 常量 |
| 移除在线翻译（完全离线） | 删除文件末尾引用 translate.js 的两段 `<script>` |

## 常见问题

- **密钥弄丢了还能找回吗？** 密钥不在任何服务器留存。可在本机记录中心（发起人密钥进入）重新打开报告并复制密钥，或从导出的 PNG / TXT / JSON 中找回；若记录已清空且没有任何备份，则无法恢复——请养成测完即保存密钥的习惯。
- **密钥给别人安全吗？** 密钥就是报告本身（编码而非加密），只发给允许查看结果的人即可。
- **提示「密钥不正确」？** 请确认密钥以 `CSX1-` 开头且复制完整；页面会自动忽略密钥中的空格与换行。
- **微信里下载不了图片 / 文本？** 点右上角「···」→「在浏览器打开」后再下载；TXT 内容也可一键复制。
- **想完全离线使用？** 删除文件末尾引用 translate.js 的两段脚本即可——翻译只是界面多语言的可选功能，测试与密钥机制本身从不联网。

# 性格色彩测试 · 局域网团队版

一个开箱即用的性格色彩测评小工具：30 道情境题，从「红 / 黄 / 蓝 / 绿」四个维度给出主导性格、四维得分与详细解读（优势、待改进、相处与职场建议）。

支持两种使用方式：

- **局域网服务模式（推荐）**：主机运行单个 EXE，自动生成二维码，同一 WiFi 下的手机扫码答题，所有记录集中保存在主机，管理员后台统一查看 / 导出 / 删除；
- **纯离线单文件模式**：直接双击 `server/web/index.html`，无需任何环境，记录保存在当前浏览器。

> 本仓库中的「XXX公司」为占位署名，请替换为你自己的名称（见下方"自定义"一节）。

---

## 功能特性

- 30 题快速测评（约 3–5 分钟），四维得分与主导性格判定，同分并列也有明确提示
- 详细报告：主导性格卡、四维得分条（含"显著主导 / 明显倾向"分级）、性格解读、优势与待改进、**相处与职场建议**（在团队中 / 在关系里）
- 三种导出：PNG 长图、TXT 文本、PDF（浏览器打印 → 另存为 PDF）
- **6 位报告密码**：每份报告对应一个去易混淆字符的短码，本人随时在首页凭密码调出报告，管理员也可在后台查看并复制发给本人
- **管理后台**：查看所有设备提交的完整报告、PNG / TXT / PDF / 删除、一键导出全部记录、修改管理密码
- **自动刷新**：手机提交后，后台列表约 5 秒内自动出现，无需手动刷新
- **登录记忆**：刷新页面自动恢复管理员登录（关闭标签页后需重新输入）
- **离线补传**：某台设备若曾因网络原因进入离线模式，下次打开页面会自动把未同步记录补传到主机（主机按记录编号幂等去重，不会重复）
- **公网扫码（可选）**：支持内网映射（如各种 frp / 映射服务），把公网地址填入二维码页即可生成公网二维码
- 数据 100% 本地：所有记录只存在主机磁盘上，不上传任何第三方服务

## 快速开始

### 1. 启动服务

- 直接双击 `PersonalityColorTest.exe`（Windows，免安装）
- 或自行编译：安装 [Go](https://golang.google.cn/dl/) 1.20+ 后，双击 `build.bat`，或在 `server/` 目录执行 `go build -o ../PersonalityColorTest.exe .`

### 2. 手机答题

程序启动后自动打开二维码页（首次请允许防火墙，勾选"专用网络"）。手机连接同一 WiFi 扫码答题，提交后得到 6 位报告密码。

### 3. 管理后台

首页输入**管理员密码**进入后台。

> ⚠️ 默认管理密码为 `12345678`，保存在主机 `config.json`，**请务必第一时间在后台修改**。

### 4. 公网访问（可选）

在二维码页「公网扫码」处粘贴你的内网映射地址（例如 `https://xxxx.example.com/`），页面会自动生成公网二维码与对应链接。

## 数据与隐私

| 文件 | 位置 | 内容 |
|---|---|---|
| `records.json` | 与 EXE 同目录 | 全部测试记录（答题明细、得分、报告密码） |
| `config.json` | 与 EXE 同目录 | `{"publicURL":"","adminPwd":"12345678"}`（首次运行自动生成） |

- 关闭程序窗口（或 Ctrl+C）即停止服务
- 备份 / 迁移：复制上述两个文件即可
- 忘记管理密码：打开 `config.json` 查看，或删除该文件后重启恢复默认
- 服务模式下管理密码明文保存在主机的 `config.json`（供 API 校验）；离线单文件模式下密码仅以 SHA-256 哈希保存在浏览器 `localStorage`，页面源码不包含任何密码

## 离线单文件模式

不想启动服务时，直接双击 `server/web/index.html`：

- 记录只保存在当前浏览器，不支持跨设备共享与管理后台集中查看
- 首次进入管理后台会引导设置一个管理密码（仅存哈希于本浏览器）
- 报告与导出功能与团队版一致

## HTTP API（服务模式）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/info` | 服务信息（模式、端口、记录数、局域网/公网地址） |
| POST | `/api/records` | 提交一条记录（幂等：相同记录编号只保存一次） |
| GET | `/api/records` | 管理员获取全部记录（请求头 `X-Admin-Pwd`） |
| GET | `/api/records?key=XXXXXX` | 凭 6 位报告密码查询单份报告 |
| POST | `/api/admin/password` | 修改管理密码（`{"oldPwd":"...","newPwd":"..."}`，需 `X-Admin-Pwd`） |
| GET | `/qr` / `/qr.png` | 二维码页 / 动态二维码图片 |

## 自定义

- **公司名 / 署名**：在 `server/web/index.html` 中全局搜索 `XXX公司`，替换为你的名称（共 6 处：页面页眉页脚、TXT、PNG、PDF 导出）；
- **默认管理密码**：`server/main.go` 中的 `defaultAdminPwd` 常量；
- **题目**：`server/web/index.html` 中的 `QUESTIONS` 数组（每题四选项对应四色）；
- **报告文案**：`server/web/index.html` 中的 `PROFILES` 对象（关键词、解读、优势、待改进、相处与职场建议）。

## 常见问题

- **双击 EXE 闪退？** 多为端口被占用，用命令行运行：`PersonalityColorTest.exe -port 9000`
- **手机扫码打不开？** 确认手机与主机在同一网络；部分路由器开了"AP 隔离"会阻断，可关闭或改用公网映射
- **防火墙弹窗？** 勾选"专用网络"并允许；错过弹窗可到 防火墙 → 允许应用 重新勾选
- **某台手机测完后台看不到？** 新版会自动补传：让那台手机重新打开页面即可（看到"已连接主机，本机记录将自动同步"即补传成功）
- **PDF 怎么导出？** 点击 PDF 后会弹出打印窗口，在"目标打印机"中选择"另存为 PDF"
- **想改用其他端口 / Linux 部署？** `-port` 指定端口；交叉编译：`GOOS=linux GOARCH=amd64 go build`
